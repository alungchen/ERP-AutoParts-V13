======================================================================
  日報明細表匯入說明 (支援多個 XLS/XLSX 處理)
  ERP-AutoParts-V13 | 最後更新：2026-06-10
======================================================================

【步驟 1】準備 XLS / XLSX 報表檔案（支援三種放置方式，擇一即可）：

  👉 方式 A：只放單一檔案，檔名改為：
      list_to_upload.xls (或 .xlsx)

  👉 方式 B：同時處理多個檔案，直接將檔案放到專案根目錄下：
      例如：20251231.xls, 20260101.xls, 20260102.xls...
      （系統會自動搜尋根目錄下所有非暫存的 Excel 檔並一次匯入）

  👉 方式 C：使用指定檔案或目錄（見下方進階說明）

----------------------------------------------------------------------

【步驟 2】開啟終端機，執行匯入指令：

  ★ 上傳到【雲端】（正式環境）：
    node scripts/import_daily_report_xls.cjs --branch=xizhi --remote

  ★ 匯入到【本地】（本機開發測試）：
    node scripts/import_daily_report_xls.cjs --branch=xizhi

  分店代號支援：
    xizhi    = 汐止店 (預設)
    songshan = 松山店
    linkou   = 林口店

----------------------------------------------------------------------

【完成】完成後瀏覽器按 F5 重新整理，網頁即會顯示所有新單據。

======================================================================
  注意事項
======================================================================

・重複匯入安全：即使同一個單號在多個檔案中重疊，或重複匯入同一個檔案，
  系統也會自動以 doc_id 進行覆蓋去重，絕對不會產生重複的單據。
・效能優化：多檔案處理時，系統會將所有檔案合併產生單一 SQL，
  只對資料庫進行一次性批量執行，上傳速度極快。
・單別自動識別：XLS 的「單別」欄位（銷貨/銷退/進貨/進退）會自動對應。

======================================================================
  進階用法 (自訂多檔案路徑)
======================================================================

  👉 1. 指定多個特定檔案（用英文逗號隔開）：
     node scripts/import_daily_report_xls.cjs --file="D:\Downloads\20260101.xls,D:\Downloads\20260102.xls" --branch=xizhi --remote

  👉 2. 直接指定一個目錄（會自動掃描該目錄下所有 Excel 檔案）：
     node scripts/import_daily_report_xls.cjs --file="D:\Downloads" --branch=xizhi --remote
