  cck2 舊系統（uParts）單獨登入操作說明
  建立日期：2026-08-10
══════════════════════════════════════════════════════════════

【用途】
  自己一個人登入 cck2.uparts.info 操作舊系統（查資料、開單等），
  不需要跑爬蟲，也「不需要」再向管理員申請新的裝置授權。

──────────────────────────────────────────────────────────────
【最常用：一行指令開啟操作視窗】

  1. 在專案資料夾開啟終端機（PowerShell）
     專案路徑：C:\Users\USER\OneDrive\YTEC\AI-Gernated\ERP-AutoParts-V13

  2. 輸入以下指令並按 Enter：

     npm run open:cck2

  3. 會自動開啟一個 Chrome 視窗，直接進入 cck2 系統主畫面，
     即可開始操作。

  ⚠️ 注意：請勿關閉該終端機視窗，否則 Chrome 會一併關閉。
     之後想再開，隨時重新執行同一指令即可。

──────────────────────────────────────────────────────────────
【運作原理（為什麼不用申請裝置授權）】

  ● 舊系統用「MachineId」這個 Cookie 辨識裝置是否已授權。
    這台電腦已經有授權過的 MachineId，腳本會自動沿用。

  ● 腳本會依序嘗試以下登入狀態，用第一個能用的直接進系統：
      1. cookies_cck2_user.json （您上次自己的登入，最優先）
      2. cookies_xizhi.json     （汐止店，單據同步程式在用）
      3. cookies_songshan.json  （松山店）

  ● 登入成功後，會把您的登入狀態自動存到：
      scripts\cookies_cck2_user.json
    下次執行指令就直接進系統，不必重新登入。

──────────────────────────────────────────────────────────────
【如果視窗停在登入頁（Session 剛好全部過期）】

  直接在視窗中輸入您自己的：
      服務編號 / 帳號 / 密碼
  然後按「登入」即可。

  因為 MachineId 已由腳本先注入，裝置檢查會通過，
  「不會」再跳出「這個裝置尚未授權!!!」。
  登入成功後腳本會自動保存您的登入狀態。

──────────────────────────────────────────────────────────────
【進階用法】

  ● 指定要沿用哪一家店的 Cookie：
      node scripts/launch_cck2.cjs --from=xizhi      （汐止）
      node scripts/launch_cck2.cjs --from=songshan   （松山）

  ● 這個視窗使用獨立的瀏覽器 Profile（.chrome-profile-cck2-user），
    不會干擾爬蟲或單據同步程式。

──────────────────────────────────────────────────────────────
【相關指令一覽（其他常用）】

  npm run open:cck2          單獨開啟 cck2 操作視窗（本說明主角）
  node scripts/run_all.cjs   全自動爬蟲三階段（文字→照片→上雲端）
                             ※ 爬蟲會自動挑可用的主機與登入狀態，
                               cck 失效時自動改走 cck2
  npm run login:uparts       登入輔助腳本（刷新 Cookie 用）
  npm run sync:docs          舊→新系統單據常駐同步（每 5 分鐘）

──────────────────────────────────────────────────────────────
【疑難排解】

  Q1：跳出「這個裝置尚未授權!!!」？
      → 表示 MachineId 沒被沿用或已被後台撤銷。
        先重新執行 npm run open:cck2 一次；
        若仍出現，才需要請 uParts 管理員在後台核准裝置。

  Q2：畫面顯示「等待審核…」？
      → 已送出裝置授權申請，需 uParts 後台核准才能繼續。
        建議改用本說明的 npm run open:cck2（沿用既有授權）。

  Q3：Chrome 視窗不小心關掉了？
      → 重新執行 npm run open:cck2 即可，會直接進系統。

  Q4：換了電腦？
      → MachineId 綁定電腦，新電腦需重新取得授權
        （複製 scripts 底下的 cookies_*.json 到新電腦亦可沿用）。

──────────────────────────────────────────────────────────────
【相關檔案位置】

  scripts\launch_cck2.cjs           單獨登入腳本本體
  scripts\cookies_cck2_user.json    您自己的登入狀態（自動產生）
  scripts\cookies_xizhi.json        汐止店 Cookie
  scripts\cookies_songshan.json     松山店 Cookie
  SCRAPER_GUIDE.md                  爬蟲完整操作手冊（含本功能說明）
