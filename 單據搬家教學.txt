------------------------------------------------------
📜 歷史單據搬家教學指南 (一鍵整合全自動流程)
------------------------------------------------------
本教學將引導您如何將舊系統的歷史單據（銷貨單、報價單、進貨單等）
「整批、自動、一鍵」下載並搬移到新的 Cloudflare D1 資料庫中。

支援分店代號：
- 松山店：`songshan`
- 汐止店：`xizhi`
- 林口店：`linkou`

------------------------------------------------------
👉 核心指令：一鍵整合搬移
------------------------------------------------------
請打開 VS Code 終端機 (Terminal)，輸入以下指令，程式會自動依序執行「啟動爬蟲下載 CSV -> 轉換為 SQL -> 匯入雲端資料庫」：

💡 雲端匯入 (正式上線) 完整搬移指令：
- 松山店：node scripts/migrate_branch_documents.cjs --branch=songshan --start=2026-01-01 --end=2026-06-08
- 汐止店：node scripts/migrate_branch_documents.cjs --branch=xizhi --start=2026-01-01 --end=2026-06-08
- 林口店：node scripts/migrate_branch_documents.cjs --branch=linkou --start=2026-01-01 --end=2026-06-08

💡 本地測試 (開發測試) 完整搬移指令（在結尾加上 `--local`）：
- node scripts/migrate_branch_documents.cjs --branch=xizhi --start=2026-06-08 --end=2026-06-08 --local

💡 **進階指令：免重複爬取，直接一鍵重新匯入** (加入 `--skip-scrape`)：
- 如果您之前已經成功抓好 CSV 資料，但中途因為資料庫網路斷線、密鑰過期等原因導致「匯入階段失敗」，您**不需要重新爬取**！
- 只要在指令結尾加上 `--skip-scrape`，即可**跳過下載**，直接利用已經抓好的本地 CSV 重做 SQL 轉換並完成匯入：
  - 重新匯入汐止店：node scripts/migrate_branch_documents.cjs --branch=xizhi --skip-scrape
  - 重新匯入林口店：node scripts/migrate_branch_documents.cjs --branch=linkou --skip-scrape

------------------------------------------------------
⚠️ 裝置授權與登入說明：
------------------------------------------------------
1. 執行完整搬移指令後，程式會自動啟動 Chrome 瀏覽器。
2. **舊系統主機與「單據同步」相同**：預設連 `cck2.uparts.info`
   （可用 `--host=` 覆寫）。cck 與 cck2 的裝置授權不互通。
3. 系統會自動注入已核准的 MachineId／Cookie（含單據同步存下的
   cookies），免去各分店重新做新裝置驗證。
4. 汐止店帳號密碼會自動填入；松山店若 Session 過期，請在跳出的
   Chrome 視窗手動登入一次，程式會自動繼續下載。
5. 下載完畢後瀏覽器會自動關閉，並自動上傳至 Cloudflare D1。

------------------------------------------------------
💡 貼心小提醒：
------------------------------------------------------
1. 建議分批下載：下載整年單據時，如果時間太長（例如超過半年），ERP 系統可能會因為連線逾時中斷。建議每次抓取 3 個月到半年最為穩定。
2. 資料完整性：如果單據中的零件號碼已經存在於「產品資料庫」中，系統會自動將單據品名、規格與零件進行關聯。
3. 若出現「裝置尚未授權」，請改確認是否已走 cck2；或先執行
   `npm run sync:docs` 完成授權後再搬單據。
